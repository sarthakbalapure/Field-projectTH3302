4. **SLA Risk Prediction** (`sla_prediction.png`): Machine learning model evaluation metrics (Accuracy, Precision, Recall, F1, ROC-AUC), confusion matrix heatmap, Random Forest feature importance rankings, and interactive incident SLA breach simulator.
5. **AI Recommendations** (`ai_recommendations.png`): Explainable, priority-badged operational recommendations backed by quantitative process mining metrics with actionable mitigation steps.
